# Q-AICON Lab

Quantum website for Q-AICON Lab at Western University.

This repository contains only the generated Quantum website. GitHub Pages serves the main branch from the repository root at https://fionauwo.github.io/QAICON/.

## Updating

The editable source project is maintained separately in aicon-concepts. Build it with BASE_PATH=/QAICON/, copy the generated dist contents into this repository, then commit and push main. Do not copy a build configured for the teamweb-preview URL: its asset paths differ.
